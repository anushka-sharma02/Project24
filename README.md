# Project24
In this project, I have developed a Daily Routine Tracker App using HTML, Vanilla CSS and ReactJS. Via this project I enhanced my command on ReactJS. In this, I have implemented options to add the task that has to be done, delete the task if any wrong task is written or if the task has been completed and the options to shift the tasks up or down in the list.
